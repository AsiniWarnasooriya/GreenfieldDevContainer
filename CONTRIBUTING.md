\# Contributing



\## Workflow



1\. Create or select an issue.

2\. Create a branch from the latest main branch.

3\. Make small, focused commits.

4\. Push the branch to GitHub.

5\. Open a pull request.

6\. Request a review.

7\. Address the review comments.

8\. Merge the pull request after all checks pass.



\## Branch naming



Use the following format:



type/issue-number-short-description



Example:



feat/12-add-contact-form



\## Commit messages



Use Conventional Commit messages.



Examples:



feat(contact): add contact form



fix(validation): prevent empty email submission



docs(readme): explain contact form usage
