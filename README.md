## Requirements

- Docker Desktop
- VS Code
- Dev Containers extension

## Getting Started

1. Clone the repository.

2. Open in VS Code.

3. Press Ctrl+Shift+P

4. Select:

Dev Containers: Reopen in Container

5. Start the application:

npm install

npm start

The server will be available at:

http://localhost:3000
